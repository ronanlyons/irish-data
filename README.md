# Irish historical data: charts and downloads

Interactive charts and data files from the Centre for Economic History (CEPH) at Trinity College Dublin,
embedded on ceph.ie and ronanlyons.com. Each chart page in `charts/` is shown on those sites in a frame;
the matching data files are in `data/`.

Built from the CEPH data project. Do not edit these files by hand: they are regenerated by the build.
Map boundaries: © OpenStreetMap contributors (ODbL), via townlands.ie.

## How to cite
Each data set gives its own suggested citation on its chart page and in its Excel file, in this form:

Lyons, R. C. (2026), "Title of the data set", CEPH Historical Irish Data series, version of [date], [link to the chart page].
